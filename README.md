# Rolei: Your Next Adventure

Crie um aplicativo mobile-first chamado "Rolei".

Objetivo:

Ajudar pessoas a descobrirem bares, restaurantes, eventos, festas, shows, happy hours e experiências próximas de forma rápida e personalizada.

O conceito principal não é encontrar estabelecimentos.

O conceito principal é responder:

"O que fazer hoje?"

O design deve ser extremamente moderno, inspirado em Airbnb, Spotify, iFood e Instagram.

Visual premium.

Paleta:
